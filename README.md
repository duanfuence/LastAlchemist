# LastAlchemist

**«Книга последнего алхимика»** — алхимическая головоломка для [Яндекс Игр](https://yandex.ru/games/). Игрок соединяет стихии, открывает новые элементы и восстанавливает дневник неизвестного алхимика.

Статус: **основной игровой опыт готов к финальной проверке** (этап 2.1). 32 элемента, 30 рецептов, перетаскивание и касания, подсказки, две сюжетные записи и финал, локальное сохранение. Онлайн-сервисов нет.

## Как играть

- **Перенос:** перенесите элемент из списка на стол; положите один элемент на другой — если рецепт есть, появится новый.
- **Повторы:** участники расходуются только при новом открытии — тогда на месте цели появляется новый элемент. Если результат уже известен, оба элемента остаются на столе на своих местах (перенесённый возвращается туда, откуда его взяли), а новый способ получения всё равно записывается («Найден альтернативный рецепт»). Список элементов не расходуется, стихии доступны всегда.
- **Касания:** коснитесь элемента на столе, затем второго (на столе или в списке). Касание элемента списка без выбора кладёт его на свободное место стола.
- **Полный список на телефоне** («Все элементы») открывается вкладным листом поверх нижней части страницы; стол под ним не сжимается. Лист закрывается кнопкой «Закрыть», клавишей Esc, касанием стола и сам — после выбора элемента. Из листа элемент можно унести на стол, задержав на нём палец.
- **Первый опыт:** до первого открытия записка на столе подсказывает, какие стихии соединить и как.
- **Убрать элемент:** перенесите его обратно в список, нажмите «Убрать со стола» у выбранного элемента или клавишу Delete. «Очистить стол» убирает всё; открытия при этом остаются.
- **Клавиатура:** Tab — переход, Enter или пробел — выбор и соединение, стрелки — перемещение (с Shift — быстрее), Esc — снять выбор.
- **Подсказка** (в шапке списка): первое нажатие называет один ингредиент ещё не сделанного опыта, второе — оба. Подсказка ведёт только к открытиям, которые можно сделать из уже открытых элементов, и держится в подписи стола, пока опыт не проведён. Тайный элемент подсказывается только после всех обычных.
- **Исследованные элементы:** если из элемента больше нельзя получить ни одного нового открытия, его рисунок в списке выцветает, а после названия появляется галочка. Это окончательно: учитываются и рецепты, второй ингредиент которых ещё не найден.
- **Завершение:** когда открыты все 27 обычных элементов, в книге появляется запись на полях; после тайного Гомункула — последняя запись. Каждая показывается один раз; перечитать их можно с титула («Перечитать последние записи»).
- **Прогресс** сохраняется в браузере автоматически. Сохранение более новой версии игры не перезаписывается (игра предупреждает и работает без записи), элементы и поля из более новой базы переносятся при записи без изменений.

Формат базы и правила соединения: [docs/CONTENT.md](docs/CONTENT.md).

Архитектура и план этапов: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Требования

- Node.js 22.12 или новее (версия указана в `.nvmrc`)
- npm 10+

## Быстрый старт

```bash
npm ci                 # установка зависимостей строго по package-lock.json
npm run dev            # сервер разработки: http://localhost:5173
```

В режиме разработки SDK Яндекс Игр не подключается, игра работает на локальной платформе.
Сервер доступен и в локальной сети (адрес Vite печатает при запуске), поэтому игру можно открыть на телефоне, подключённом к той же сети.

### Первый запуск e2e-тестов

Playwright использует свой Chromium, его нужно скачать один раз:

```bash
npx playwright install chromium
npm run build
npm run test:e2e
```

Если Chromium уже установлен в системе, можно указать его: `PW_CHROMIUM_PATH=/путь/к/chrome npm run test:e2e`.

## Сборка для Яндекс Игр

```bash
npm run pack
```

Результат — `release/last-alchemist-v0.1.0.zip`. Скрипт сначала проверяет каталог `dist/`, затем распаковывает уже созданный архив в памяти и проверяет его:

- `index.html` лежит в корне архива;
- в именах файлов и папок только `A–Z a–z 0–9 . _ - /` (нет пробелов и кириллицы);
- распакованный размер не больше 100 МБ (считаются десятичные мегабайты — строже требования), при превышении 30 МБ (бюджет проекта) выводится предупреждение;
- ссылки в `index.html` относительные, внешних ресурсов нет, SDK подключён как `/sdk.js`.

При любой ошибке команда завершается с ненулевым кодом. Этот архив загружается в черновик игры в консоли разработчика Яндекс Игр.

### Проверка с SDK площадки локально

Официальный инструмент Яндекса проксирует `/sdk.js` и добавляет CSP игры:

```bash
npm run build
npx @yandex-games/sdk-dev-proxy@0.0.2 -p dist --dev-mode
```

Для проверки на черновике в консоли: `npx @yandex-games/sdk-dev-proxy@0.0.2 -p dist --app-id=<ID черновика> --csp`. Нужен доступ к серверам Яндекса.

### Интеграция с площадкой

- **Язык** определяется при запуске через `ysdk.environment.i18n.lang` (требование 2.14), без площадки — по `<html lang>`. Поддерживается только русский: другой язык площадки показывает русский интерфейс. Чтобы язык был известен до первого текста, игра ждёт инициализации SDK, но не дольше 6 секунд, затем продолжает без него.
- **Пауза:** `game_api_pause`/`game_api_resume` и скрытая вкладка останавливают анимации и звук; потеря фокуса окна (`blur`) — только звук. Причины складываются: звук возвращается, когда сняты все, и только если он включён в настройках.
- **Готовность:** `LoadingAPI.ready()` — после загрузки шрифтов и показа обложки.

## Принятые технические решения этапа 0

- **TypeScript 6.0**, а не 7.0. typescript-eslint поддерживает TypeScript до версии ниже 6.1.
- **Без UI-фреймворка и игрового движка**: DOM + CSS, SVG встраиваются в документ, поэтому цвета туши задаются темой.
- **Шрифты** Cormorant Garamond и Marck Script (лицензия SIL OFL) включены в сборку из пакетов `@fontsource`. Внешние шрифты заблокировала бы CSP площадки.
- **SDK**: используются только `YaGames.init()`, `features.LoadingAPI.ready()` и события `game_api_pause` / `game_api_resume`. Если SDK не загрузился, игра работает без него.
- **Язык**: только русский. Чтобы добавить язык, нужно создать каталог в `content/locales/` и зарегистрировать его в `src/i18n/index.ts`. Проверка типов и тест не дадут пропустить ключ.

## Художественная система (этапы 1.2–1.4)

- **Книга — забытый фолиант в тёмной лаборатории.** Стол из морёного дуба уходит во тьму; единственный тёплый свет — свеча сверху слева, тени холодные, серо-зелёные. Почти чёрный кожаный переплёт, медные угловые накладки с патиной, потускневшее золотое тиснение, обрез страниц, глубокая тень у корешка, лента-закладка. Страница старая и обожжённая по краям, но в середине, где читают, остаётся светлой. Фактуры процедурные и бесшовные.
- **Иллюстрации элементов — «тушь и акварель» в светотени свечи.** Каллиграфический контур переменной толщины, прозрачные заливки с пигментным краем и зерном, гравюрная штриховка, холодная тень формы (`coldShade`) и отражение пламени свечи на блестящих поверхностях (`candleReflection`). Золото — только у редкого и потускневшее. Каждый рисунок описан кодом в `tools/art/elements/<id>.ts` и растрируется в WebP 256×256. Оформление книги (медные накладки) рисуется тем же конвейером (`tools/art/ui`).
- **Материалы и свет (этап 1.4).** Все 32 элемента нарисованы в одной системе. Материал передаётся рельефом: карта высот (купол формы и шум фактуры) освещается свечой фильтрами SVG (`relief`): камень и земля матовые и зернистые, металл и мокрая грязь блестят, у дерева и железа волокна. К свету — тёплый край (`rim-warm`), в тени — холодная собственная тень (`core-cold`), под предметом — тень на столе (`groundShadow`). Вода, стекло и ртуть показаны оптикой: тёмная кромка (`rimDark`), преломление, отражения свечи. Свечение есть только у того, что светится само: огонь, лава, вулкан, энергия, взрыв, гроза, гомункул. Общие детали (облака, кристаллы, валуны, горки, листья, дождь) — в `tools/art/kit.ts`.
- **Атмосфера (этап 1.4).** Над книгой «дышит» косой луч свечи, свет неровно мерцает, в луче плавают редкие пылинки. Когда книгу раскрывают, свет вспыхивает и из корешка поднимается облачко пыли. Анимируются только прозрачность и сдвиг, слой не перехватывает нажатия. Эффекты отключаются в панели настроек («Живой свет и пылинки», `localStorage` → `last-alchemist:atmosphere`), при `prefers-reduced-motion` пылинок нет и свет не мерцает.
- **Размеры экрана (этап 1.4).** На мониторах от 1800×1050 разворот, элементы и текст крупнее. На экране 320×568 обложка помещается без прокрутки, а счётчик и кнопка списка не переносятся.
- **Элементы лежат на странице.** Нет кружков-медальонов. Тень рисунка — отдельный слой: при переносе рисунок поднимается, а тень остаётся на бумаге.
- **Открытие.** Участники растворяются в свете, над местом соединения — вспышка, золотое кольцо и искры, результат проявляется. У тайного открытия знак сильнее, а сияние дольше. У повтора — только чернильный дымок, без золота. Слой реакции не перехватывает нажатия и удаляется сам; при `prefers-reduced-motion` анимаций нет.
- **Звук.** Шесть коротких звуков синтезированы кодом: элемент на странице, реакция, неудача, открытие, тайное открытие, книга. Аудиоконтекст создаётся только после первого жеста игрока. На паузе площадки и в скрытой вкладке звук приостанавливается. Недоступный файл просто молчит.
- **Музыка «Ночь в лаборатории».** Оригинальная композиция на 128 секунд, синтезированная кодом без чужих сэмплов (`tools/audio/music.ts`). В ней бурдон, смычковые, хор на формантах, валторна, арфа (Карплус — Стронг), колокола, ветер и свёрточная реверберация каменного зала. Цикл бесшовный (точки `loopStart`/`loopEnd`). Музыка загружается только после первого жеста и только если включена. Действия игрока её не перезапускают, звук открытия ненадолго приглушает её.
- **Управление звуком.** Кнопка-динамик в панели над книгой открывает настройки: «Весь звук», «Музыка» и «Эффекты», у музыки и эффектов отдельная громкость. Настройки хранятся в `localStorage` (`last-alchemist:sound`), прежний формат читается.
