# Этап 2.1: надёжность, помощь игроку, завершение книги

Основа — отчёт аудита `review/stage-2.0-audit/REPORT.md`. Рецепты, баланс, правила соединения и повторных комбинаций не менялись, иллюстрации и стиль — тоже.

## 1. Техническая надёжность

### Язык через SDK

- **Что сделано.** У платформы появилось поле `language`.
  - `YandexPlatform` читает `ysdk.environment.i18n.lang` безопасно: при ошибке или неожиданном значении получается `null`.
  - `LocalPlatform` возвращает `null`, тогда язык берётся из `<html lang>`.
  - `resolveLocale` выбирает поддерживаемый язык; любой, кроме русского, показывает русский интерфейс.
  - `document.documentElement.lang` выставляется по итогу.
- **Порядок запуска изменён.** Текст создаётся после инициализации SDK, иначе язык нельзя определить «при запуске». Шрифты грузятся параллельно. Чтобы зависший SDK не оставил пустой экран, `createPlatform` ждёт его не дольше 6 с, затем продолжает без площадки.
- **Подтверждение требования.** Пункт 2.14 подтверждён по выдержке официальной страницы в поисковой выдаче: определять язык через SDK даже для одноязычной игры. Сама страница из этой среды не открывается (DNS). Вне контейнера ошибок нет: e2e-страж консоли пропускает только ожидаемый 404 для `/sdk.js`.

### Звук при потере фокуса

- **Причины паузы складываются.** В `PauseState` добавлено `trackFocus`: `blur` ставит паузу, `focus` снимает её, только если `document.hasFocus()` действительно `true`. Повторные `blur`/`focus` итог не меняют.
- **Две паузы в `main.ts`:**
  - пауза площадки и скрытая вкладка — анимации (`data-paused`) и звук;
  - потеря фокуса — только звук. Требование касается звука; к тому же iframe без фокуса до первого щелчка иначе замораживал бы обложку.
- **Начальное состояние.** У платформы появилось `paused`: если вкладка скрыта уже при запуске, звук знает об этом сразу.
- **Исправлена найденная ошибка.** Если первый жест игрока приходился на паузу, созданный аудиоконтекст не приостанавливался. Теперь он создаётся молчащим.
- **Источник музыки всегда один.** Это проверено unit-тестом (пять циклов пауза/возврат) и e2e.
- **Автовоспроизведение не обходится.** Контекст по-прежнему создаётся только жестом; после возврата звук звучит, только если включён в настройках.
- **Подтверждение требования.** Формулировку «при потере фокуса игрой звук останавливается» удалось подтвердить только по выдержке поиска. Шлёт ли сама площадка `game_api_pause` при потере фокуса iframe, проверить без настоящего контейнера нельзя, поэтому пауза сделана в игре.

### Защита сохранений

| Запись | Что происходит |
|---|---|
| Нет записи | новая книга |
| Повреждённый JSON или структура | резервная копия, затем чистая книга. Если копию записать не удалось — книга работает без записи, исходник не тронут. Прежняя копия не затирается: новая кладётся рядом с отметкой времени |
| Формат новее (`v` больше известного) | статус `newer`: читается то, что понятно, запись **запрещена** до перезагрузки, игрок видит пояснение. Исходная строка остаётся байт в байт |
| Неизвестные элементы, рецепты, поля, сюжетные записи (более новая база в том же формате) | не отбрасываются, а переносятся в запись при каждом сохранении. Раньше старая версия молча стирала прогресс новой — это второй путь потери данных, найденный при работе |
| Прежняя версия схемы | переводится миграциями в памяти. Запись в хранилище меняется только при первом изменении прогресса; сбой миграции — повреждённая запись, а не исключение |
| Сохранение этапа 1.4 | читается без потерь, без действий игрока не перезаписывается |

Формат остался v1. Новое поле `story` необязательное, поэтому совместимость сохранена в обе стороны: старые записи читаются, а прежняя версия игры поле просто игнорирует.

## 2. Помощь игроку

Модуль `src/core/progress/exploration.ts` работает на той же базе рецептов (`ContentPack.recipes`).

### Отметка «исследован»

- **Условие.** Ни один рецепт с участием элемента не даёт неоткрытого результата, включая рецепты, второй ингредиент которых ещё не найден. Поэтому отметка окончательная, а не «пока нечего делать».
- **Тайный элемент.** Он учитывается, но не раскрывается: Жизнь и Ртуть не отмечаются, пока Гомункул не найден.
- **Как показано.** В списке рисунок выцветает, после названия — галочка пером. Есть пояснение при выборе элемента и в подписи для экранного чтения. В момент открытия, исчерпавшего элемент, подпись сообщает об этом.

### Кнопка «Подсказка»

- **Где.** В шапке списка, рукописная, как «Все элементы». Бесплатно, без валюты и внешних подключений.
- **Алгоритм.** Выбираются только *готовые* открытия: оба ингредиента у игрока, результат ещё не открыт. Из них — самое раннее по цепочке (глубина из `computeDepths`), затем по порядку базы.
  - Тайный элемент подсказывается, только когда открыты все обычные.
  - Первое нажатие называет один ингредиент (более поздний по цепочке), второе — оба.
  - Подсказка держится в подписи стола и подсветке списка, пока её открытие не сделано. Если игрок сделал другое открытие, она остаётся прежней.
- **Пустые случаи.** Если подсказывать нечего, игра честно говорит, что книга заполнена. Если из открытого ничего не получить, так и сообщает; для этой базы такое не встречается, но проверено на искусственной.
- **Доказательство в тестах:**
  - если следовать только подсказкам, открываются все 28 элементов, ни одна подсказка не ведёт к известному, Гомункул — последний;
  - в 500 случайных достижимых состояниях подсказка выполнима и ведёт к неоткрытому.

### Раскладка

- На узких экранах подпись списка сокращена до «Все» (полный текст — в `aria-label`).
- В раскрытом листе на экранах до 440 px подсказка скрыта: иначе на 320 px шапка вылезала за край на 36 px, это поймал e2e.

## 6. Известные ограничения

- **Язык.** Порядок запуска стал зависеть от SDK: на площадке обложка появляется после `YaGames.init()`, не позже чем через 6 с. На реальной площадке время не измерено.
- **Подсказка** не сохраняется между перезагрузками: после перезагрузки она начинается заново с ингредиента. Это сознательно, чтобы не менять формат ради мелочи.
- **В режиме «новая версия»** игра работает без записи до перезагрузки. Прогресс этого сеанса теряется — так выбрано, чтобы не затереть данные новой версии.
- **Две вкладки** по-прежнему затирают друг друга (Б1 из аудита, не входило в этап).
- **Тексты записей** — моя редакция: оцените их сами.
