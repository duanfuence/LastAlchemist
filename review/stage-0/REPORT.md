# Визуальная проверка этапа 0

## Как снимались скриншоты

- **Браузер.** Chromium 141, production-сборка (`npm run build`), локальный `vite preview`.
- **Размеры.** 1440×900 (масштаб экрана 1×), 390×844 и 844×390 (масштаб 3×, сенсорный ввод).
- **Исходные снимки** (до исправлений) лежат в этой папке: `*.png` и `report.json` с журналом консоли.
- **Снимки после исправлений** сохраняются локально в `review/local/stage-0-fixes/` и в Git не попадают (папка в `.gitignore`). Там же:
  - `compare/` — склейки «до/после»;
  - `report.json` — консоль, сеть, обработчики событий.
- **Повторить съёмку:** `npm run build`, `npx vite preview --port 4173` и скрипт съёмки из сессии разработки.

## Осталось

1. **Заглавная «С» в Marck Script визуально отделена от остального слова.** Проверено: так нарисован сам шрифт, отступ одинаков при любых настройках рендеринга, кернинга и лигатур. Настройками не исправляется. Варианты: оставить или заменить рукописный шрифт (например, Bad Script или Caveat, оба с кириллицей и лицензией OFL). Нужно решение владельца.
2. **Реальные устройства не проверялись.** Проверено только в Chromium с эмуляцией сенсорного ввода. Safari на iOS, Firefox и живые телефоны не проверены.
3. **Реальный SDK Яндекс Игр не проверялся:** серверы Яндекса недоступны из среды разработки.
4. **На маленьких экранах «Четыре начала» прокручиваются** (360×640, 640×360, 844×390). Это допустимо по требованиям, прокрутку показывает подсказка.
5. **Едва заметная граница внутренней тени у верхнего края в ландшафтной ориентации** (перепад 1–2 уровня яркости). Не исправлялась: на глаз почти не видна.
6. **Экраны шире 1920 px не проверялись.** Разворот ограничен 1400×940 px, по бокам остаётся стол.
7. **В архиве лежат резервные `.woff` к каждому шрифту** (около 150 КБ). Современные браузеры их не загружают, но они занимают место в архиве.
